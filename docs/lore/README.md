# Lore Planet Forge — kopia z Projektu

Pliki w tym folderze (oprócz `nazwy-w-grze.md`) to **kopia** dokumentów lore z Projektu „Planet Forge” na claude.ai, stan z 2026-10-22. Lore powstaje tam; tu jest po to, żeby Claude Code znał kanon.

- `CANON_STATUS.md` — jedyne źródło prawdy: kanon K-xxx, decyzje częściowe, robocze, odrzucone, rejestr wyjątków W-xxx. **Czytaj przed każdą treścią fabularną.**
- `WORLD_PILLARS.md` — deklaracja tożsamości (K-011) i filtr 4 pytań.
- `COSMOLOGY.md` — zasady świata (K-012); Faza 2 w toku.
- `OPEN_QUESTIONS.md` — otwarte kwestie O-xxx.
- `LORE_CHANGELOG.md` — historia zmian kanonu.
- `nazwy-w-grze.md` — (plik repozytorium) gdzie w kodzie są nazwy dotykające lore i rozbieżności do poprawienia w Projekcie.

Zasady: nie zmieniaj tych plików z poziomu kodu — zmiany kanonu zapadają w Projekcie i wracają tu jako nowa kopia. Własnej propozycji nie awansuj do kanonu (CANON_STATUS: „brak sprzeciwu to nie akceptacja”).
